Page tierce de démonstration

Cette page est servie depuis une autre origine que celle d'Aria : l'API ne répond que si l'origine de cette page figure dans les domaines autorisés de la clé. Lancer par exemple python -m http.server 8080 dans le dossier docs, puis ouvrir http://localhost:8080/access-demo.html (autoriser l'origine http://localhost:8080 dans l'onglet « Accès tiers »). Le micro exige HTTPS ou localhost, et le navigateur doit avoir accepté une fois le certificat d'Aria (ouvrir l'adresse ci-dessous dans un onglet).
